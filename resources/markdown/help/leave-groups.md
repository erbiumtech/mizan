## What this is

A bundle of leave types assigned to employees: office staff get one set,
the factory floor another, contractors a third. An employee's group decides
which types the request form offers and which years are opened for them. The
**default** group applies to everyone without one; with no default group,
every active type applies, which is how it worked before groups.

## Setting one up <!-- requires: LeaveTypeUpdate -->

Click **New**, name it, tick the types. Assign it on the employee record.
