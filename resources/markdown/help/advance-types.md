## What this is

The kinds of advance the company gives — a salary advance, an Eid advance, a
loan — each with its limits: a maximum amount, a maximum number of
instalments, simple interest added to what is recovered, and how many of
that kind one person may have running at once.

## Adding one <!-- requires: AdvanceUpdate -->

Click **New**. An application against a type is checked against these limits
when it is approved, not when it is typed, so a limit changed later applies
to what is still waiting.
