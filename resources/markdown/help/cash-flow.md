## What this shows

Where the company's cash actually went, by the indirect method — starting
from profit and adjusting for everything that moves cash without touching the
profit and loss (and vice versa). Profit and cash are different things; this
report is the reconciliation between them.

## Using it

Set **From** and **To** to the period you want. There's no default start date
— pick one, since a cash flow statement without a starting point has no
opening balance to reconcile from.

**Download PDF** exports the currently selected period.

## Roles and permissions

Requires `ReportView`, gated behind the Accounting module being enabled for
the company. This is read-only — there is nothing on this page that changes
any figures.
