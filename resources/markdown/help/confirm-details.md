## What this is

Where you confirm that the phone number and the address the company holds for you
are really yours. It only appears when there is something to confirm, and it is the
one screen you can open while something is outstanding.

Nothing here changes your details. If a number or an address is wrong, edit your own
record under Employees — that goes to HR for approval — and then come back and
confirm the new one.

## Confirming a phone number

**Send a code** puts a six-digit code on WhatsApp to that number. **I have the code**
takes it. It is good for fifteen minutes.

Five wrong tries and the code is burnt; send a new one. That is not meant to be
annoying — a six-digit code with unlimited guesses is not a check at all.

The emergency contact's number is confirmed the same way, by a code to *that*
number. It is the one worth checking, because it is the number nobody dials until
the day it matters.

## Confirming an address

**Send a code** produces a letter with a code in it, for HR to post to you. Typing
the code back is what proves you live there, which is why it cannot be emailed — an
email to you proves only that the email address is yours.

The code on a letter is good for a month.

## Why a confirmed thing can go back to unconfirmed

A confirmation is about a *value*, not about you. Change your phone number and the
old confirmation no longer says anything about the new one, so this screen asks
again. Nothing has gone wrong and nobody has undone anything.

## What happens until you finish

Every other screen sends you back here. You can still sign in — that is deliberate,
because this is where you finish it — and you can still sign out.

If something on the list is not something you can finish yourself, it is shown
separately under *Also outstanding*. A missing document is the usual one: send it to
HR, and when they have it on file the block lifts.

## Roles and permissions

No permission. Everybody with an employee record can reach it, and everybody sees
only their own.
